# Import flowcharts into SmartDraw

Files in this folder:

| File | Best for |
|------|----------|
| `admin-flowchart.svg` | SmartDraw **File → Import → SVG** (quick, looks correct) |
| `admin-flowchart.vdx` | SmartDraw **File → Import → Visio** (editable shapes) |
| `seller-flowchart.svg` | Same SVG import for the seller chart |

## Recommended (easiest)

1. Open [SmartDraw](https://www.smartdraw.com/) (web or desktop).
2. **File → Import** (or **Insert → Picture / SVG** depending on version).
3. Choose **`admin-flowchart.svg`**.
4. Resize to fit the page.
5. **File → Save** as a SmartDraw document.

## Visio import (editable shapes)

1. In SmartDraw: **File → Import → Visio**.
2. Select **`admin-flowchart.vdx`**.
3. If connectors are missing after import, use SmartDraw’s **Connector** tool and link the shapes top→bottom (straight / right-angle lines).
4. Decision diamonds: use SmartDraw **Decision** shape and replace the plain boxes if Visio import flattened them.

## Seller chart

Use **`seller-flowchart.svg`** with the same SVG import steps as the admin chart.
